# Day1 Linux basic practice
Commands practiced:
- pwd: 打印当前所在工作目录 print current working directory
- ls: 列出文件夹内文件 list files
- ls -l: 查看文件详细信息 show detailed file info
- ls -a: 显示所有文件（包含隐藏文件） show hidden files
- cd: 切换目录 change directory
- mkdir: 创建文件夹 make directory
- touch: 创建空文件 create empty file
- cat: 查看文件内容 view file content
- echo: 输出/写入文本 write text into file
- whoami: 查看当前登录用户名 show current user
- uname -r: 查看系统内核版本 check kernel version
- sudo apt update: 更新软件源信息 update package source
